# Companion assets

`canopy.png` is an original landscape generated with OpenAI Image Gen on November 2, 2026. Max approved its actual Figma Play and Controller frames (`31:57`, `31:133`) for the public release before implementation. No official Elden Ring screenshot or mod binary is bundled.

The window icons and switch images are 2x exports of the editable companion controls in Figma. Display icons at 16 DIP and switches at 54 by 30 DIP.

`Fonts` contains static TrueType resources derived from the official Google Fonts Manrope, Cormorant Garamond and Cinzel families, with full SIL Open Font License notices. The files are embedded; licenses are embedded and copied into publish output. WPF resolves Manrope Normal/Medium/SemiBold/Bold, Cormorant Garamond Medium, and Cinzel Normal without installing fonts globally.

`asset-manifest.json` records the current runtime file hashes and source metadata. Variable fonts and preparation dependencies are not bundled.
